# **Выбор метрик для отправки**
Для отправки выбраны следующие метрики:
- Количество обработанных строк - дает понимание какой поток данных в физ.единицах (строк) проходит через процесс
- Количество выполняемых задач (успешные или нет) - позволяет посчитать рейт неудачных запусков, для отправики уведомлений о сбоях
- Метрики операций чтений и записи данных в БД - позволяет посмотреть обрабатываем объем данных в физ.единицах (байты, мегабайты)
- Потребление CPU - позволяет оценить состояние системы, требуется ли масштабирование
- Потребление Памяти - позволяет оценить состояние системы, требуется ли масштабирование

PS: По-умолчанию "из коробки" отправляются все эти метрики и больше.

# **Выбор подхода обработки логов**
Сборка логов будет происходить с помощью Logstash и Filebeat для их передачи в ELK-систему.
Является промышленным стандартом, позволяет не нагружать само бизнес-приложение на отправку логов по сети.
В Kibana(ELK) удобнее всего выполнять разбор и мониторинг логов.
