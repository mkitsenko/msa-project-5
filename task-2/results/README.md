Использовать Apache Airflow. Является одним из самых распространенных Open Source оркестраторов.

- Содержит большое количество готовых коннекторов к различным система
- Позволяет быстро реализовывать простые DAG извлечения данных
- Команда имеет опыт работы с данным инструментом

План:

- Развернуть Apache Airflow с помощью Helm-чарта.
- Создать подключение к источнику в настройках Airflow (connections).
- Реализовать DAG по шаблону из задания #1.
- Использовать кастомный PythonOperator, который будет читать данные с помощью pandas и сохранять их в виде csv-файла.
- Установить расписание на 6 утра (0 6 * * *).
- Указать в DAG настройки повторов при падении выполннения.
- Указать email на который отправлять уведомление в случае сбоев.
